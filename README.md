## Current State of This Microlib
The repo is currently configured for testing and not for distribution.
Two features are available; make a menu using a set of strings or make a menu with text input using a set of strings and a set of indices to identify text input lines.
This is meant to replace an internal project called menuDipity, which ran on ncurses.
This is basically just a set of helper functions to make templating less annoying.
